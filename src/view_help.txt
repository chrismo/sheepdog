sd view - the Flock page: every branch sd watch tracks, where its PR stands
and who moves next, live in the browser.

Usage: sd view [--port <n>] [--no-open]

  Starts a local server on 127.0.0.1, prints its URL and opens it in the
  browser, then serves until Ctrl-C. The page reads the state each sd watch
  pass caches, and asks again every 30s. It shows the last pass's time: with
  the watcher stopped, that time stops moving. A branch's timeline has its
  PR's commits, CI and merge from GitHub (gh). A branch is there from its
  first pass, and stays until the watcher drops its cache: after it's
  unenrolled, or once its merge is notified.

  The Map (/map, linked from the Flock) is sheepdog's own code: each file
  under src/ sized by its lines, the share of it in functions over clippy's
  cap (tests/lint-ratchet.txt), and the open issues that name it (one gh
  issue list). It reads the checkout sd was built from, whatever repo sd
  view runs in.

  GitHub data is cached under <state>/github/ and served at once; the first
  read after it's a minute old fetches it again in the background, so with
  no page open nothing is asked. A file not fetched for a week is deleted.
  The Map and a branch's timeline show its age and have a refresh button.
  While the Flock is open, a branch whose cached state is a minute old is
  checked again (sd watch refresh), one at a time, and its card shows when;
  its refresh button checks every branch again.

  A branch's drill-in has a button for NEXT's first step when it's the
  agent's or sheepdog's: it runs sd act <verb> <branch> in the branch's
  repo, the same command the watcher's autoRun pass launches for that step,
  under the same timeout (SHEEPDOG_WATCH_TIMEOUT, settings.stepTimeout),
  one step at a time; the branch is checked again when it ends, so the page
  shows the result. The step runs only if it's still NEXT's first; your
  steps and waits have no button. The step is sd view's: Ctrl-C ends it as
  it would a hand-run sd act, and sd view's log says it was stopped.

  --port <n>   the port (default 7377; 0 picks a free one)
  --no-open    print the URL, don't open the browser
