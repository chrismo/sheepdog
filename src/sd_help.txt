sd - sheepdog, the PR pipeline: it tends a branch's PR until it can merge.

Usage: sd <verb> [<args>]

Verbs:
  state         where a branch's PR stands, and what's next
  act           the pipeline's verbs: start, push, enroll, address, ship...
  watch         the watcher: one pass, or install it as a launchd job
  config        harness and settings
  harness       probe: check the installed harnesses after an upgrade
  review-local  the default local reviewer (sd act review runs it)
  view          the Flock page: every enrolled branch, live in the browser

sd <verb> --help for each verb's own usage.
